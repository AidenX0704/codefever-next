CodeFever 设计令牌 v3

以《Git Platform Design System V3》为基线、对齐本仓库现状后落成的可执行令牌集。 V3 的三层架构、语义主题、系统字体、低阴影、动效分档与五阶段迁移全部保留； 这次补的是「能直接抄进 theme.css 的最终值 + 逐条对比度实测 + 与现有 --cf-* 的别名映射」， 并修掉 V3 原始值里 4 处达不到 AA 的组合。

V3 基线 3 层单向依赖 浅 / 深双模 白壳 · 单密度 控件 34 / 行高 42 对比度逐条实测 时间统一到秒 动效硬上限 220ms
01

视觉基线与不做什么

左边是要的，右边是明确禁止的。后者比前者更能防止界面走样。

视觉关键词
  • Swiss / Minimalism —— 网格、清晰层级、克制装饰
  • Developer Tool —— 技术信息密度高，但不拥挤
  • Flat UI —— 用背景、边线、排版与间距表达层级，不用大面积阴影和渐变
  • Neutral-first —— 中性色承载内容，蓝色只表达主操作与选择
  • Consistent interaction —— 同类组件全站同高、同状态、同键盘行为
不采用的视觉模式
  • 不为每个区域套一张卡片
  • 不给普通列表、表格、输入框、按钮加装饰性阴影
  • 不在整页大面积使用品牌蓝、渐变或彩色背景
  • 不让正文、时间戳、作者、路径、状态共用同一字重与颜色
  • 不用 Emoji 当功能图标；统一走 config/icons.ts 的 SVG
  • 不为单个页面单独定义按钮、圆角、输入框高度或弹窗风格
  • 不靠延长动画营造「高级感」
核心视觉层级
页面标题22–24px · 600（深色 500）
区块标题16px · 600（深色 500）
正文 / 表格14px · 400
辅助信息12–13px · --fg-muted，不降到难以辨认
技术数据--font-mono + tabular-nums
禁用信息--fg-disabled，不得用 --fg-subtle 承载大段正文

动效：硬性时间上限（V3 §8）
场景令牌 / 上限规则
按钮按下、焦点、颜色反馈0–100ms立即响应，不做缩放弹跳
Hover 进入≤100ms --dur-fast轻微背景 / 边框变化
Hover 退出≤80ms退出快于进入
菜单、Tooltip≤100ms内容尽快出现；Tooltip 可有短延迟但不得影响点击
Tab、筛选、列表选中0–100ms状态立即更新，禁止等待动画结束
抽屉 / 弹窗进入≤180ms --dur不得阻塞底层任务与键盘处理
抽屉 / 弹窗退出≤140ms先关交互层，再完成视觉收尾
局部展开 / 折叠≤160ms连续点击必须可打断
Toast 进出场≤160ms不影响其他交互
Skeleton / 进度无入场等待任务开始后立即出现
任意新增动效绝对上限 220ms超出需产品与设计共同批准；默认不允许
动效原则
动画不能成为业务状态改变的前置条件。
用户第二次操作必须能打断第一次动画，不排队等待。
只动 opacity / transform；不动画化影响布局的属性。
禁止按钮缩放弹跳、长距离滑入、连续脉冲、装饰性背景动效。
关闭动作优先立即隐藏交互目标；退出动画不得继续拦截点击或焦点。
动效不得导致滚动位置变化、表格列宽跳动、文本重排或焦点漂移。

08

相对现有 v1 改了什么

旧令牌是"抄录现值"，新令牌是"定义规则"。

V3 原始值的审计结果：4 处需要修
项V3 原值实测本次修订理由
深色 --fg-subtle #718096 4.42:1 #7b8a9f（5.05:1） 深色下差 0.08 到 AA；占位符虽不承载正文，但输入框提示看不清会直接影响填表
危险按钮的 text 变体 --ac-danger 压 --ac-danger-tint 4.41:1 文字改用 --st-danger-text（5.91:1） 差 0.09；把"动作色"和"状态文字色"分开后天然达标
实心绿 + 白字 --st-success #16a34a 3.30:1 约束：实心状态色只做圆点 / 图标 / 进度条 状态色实心块本来就不该放文字；文字一律走 --st-*-text 压 tint
边线 --bd / --bd-strong #e2e8f0 / #cbd5e1 1.23 / 1.48 记录为已知偏离，见下方补偿 WCAG 1.4.11 要求控件边界 3:1；但达标的边线（约 #767676）会让密集表格显得脏。业界主流（GitHub / Linear）同样不达标
边线对比度不足的补偿措施（三条，缺一不可）： ① 输入框 / 选择器默认边框用 --bd-strong，hover 加深到 --fg-subtle，focus 换成 --bd-focus（只变颜色，不加光晕）； ② 复选框、开关的"选中"用实心填充而非只换边框； ③ 表格不靠边线区分行，靠 --bg-hover 与留白。
其余 40 余组文本组合（含深色全部状态文字压 tint）实测均 ≥ 4.5:1，无需修订。
维度现状 v1提案 v2
