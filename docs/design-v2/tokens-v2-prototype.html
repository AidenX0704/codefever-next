CodeFever 设计令牌 v2

现有令牌是 MUI v4 主题的逐项抄录 —— 能用，但把「原始色值」「语义用途」「组件内部量」压在同一层， 导致同一个值在三个页面各写一遍、深色模式无从落地、表格密度无法切换。 v2 把它们拆成三层，并补上原体系缺的：表面层级、状态色、焦点环、语法高亮、动效与密度档位。

3 层令牌架构 浅 / 深双模 标准 / 紧凑双密度 AA 对比度内建 无新增运行时依赖
01

设计原则

四条约束，后面每个令牌都能回溯到其中一条。

01

墨为骨，蓝为脉

结构用中性墨色（表头、边线、层级），只有"可点的东西"才上蓝色。 颜色一旦用来分隔区块，动作就淹没了 —— 这是旧界面最主要的视觉噪音来源。

02

绿只属于状态

成功 / 通过 / 已合并用绿，失败 / 删除用红，待处理用琥珀。 主按钮永远不用绿 —— 否则"通过 CI"和"提交表单"读起来是同一件事。

03

靠边线分层，不靠阴影

阴影只留给真正浮起的层（菜单、弹窗、消息条）。列表与卡片用 1px 边线 + 表面色差区分， 密集页面才不会到处是灰色雾面。

04

中文优先的字面

正文 14px、标题字重 600 而非 700（中文 700 在小字号下发糊）、行高 1.5 / 长文 1.7。 不引入 Web 字体，靠系统字体栈，离线部署零额外请求。

02

颜色

原始层色阶 → 语义层角色。组件只允许引用语义层。

原始层 · 中性墨色阶（承载全部结构）
原始层 · 品牌蓝阶（唯一动作色）
原始层 · 语义色阶
语义层 · 表面与文字
语义层 · 动作与状态
语义层 · 代码与 diff

带 AA 徽标的是「作为文字压在 --bg-surface 上」的对比度实测值： ≥ 4.5:1 才可用于正文，标 仅大字 的只能用于 ≥18px 或非文本元素（占位符、禁用态）。 切换主题后这些数字会重新计算 —— 深色模式不是"调暗"，是另一套已验证的组合。

03

9 级字号 + 4 级行高。旧版只有 14 / 16 / 20 三档，长文与元信息挤在一起。

07

改了什么

旧令牌是"抄录现值"，新令牌是"定义规则"。

维度现状 v1提案 v2
层级单层平铺，60+ 个 --cf-color-* 混着原始值与用途原始色阶 → 语义角色 → 组件量，组件只准引用语义层
深色模式没有。所有值写死为浅色[data-theme="dark"] 只重绑语义层，组件零改动
表面层级只有 bg / bg-main / bg-dark 三个，语义含糊canvas / surface / sunken / raised / overlay + hover / active / selected
字号4 档（12/14/16/20），标题一律 7009 档阶梯，标题 600，行高分 4 级（紧/常规/长文）
间距只有 8px 与 4px 两个基数12 级阶梯（2→64），密度档位可整体压缩
圆角4px 通吃控件 6 / 卡片 8 / 浮层 12 / 标签 4，语义化
阴影5 条 MUI elevation 原值，肉眼难区分4 档，只给浮层；列表与卡片改用 1px 边线
状态色只有 solid，没有"底色 + 文字 + 边线"三件套每状态 4 个令牌：solid / tint / text / border，AA 已验证
焦点环只有 --cf-focus-ring: 2px（宽度），颜色未定义宽度 + 偏移 + 颜色 + halo，键盘可达性可验证
代码/diff8 个 diff 底色，语法高亮散落在组件里--tok-* 8 个语法角色 + diff 三档深浅，浅深双模
动效无令牌，各处各写 0.2s / 0.3s3 档时长 + 2 条曲线，prefers-reduced-motion 统一归零
壳层固定白壳--chrome-* 一套令牌，白壳/墨壳一行切换
放弃的东西
  • 不再逐项对齐 MUI v4 的 elevation / spacing 原值 —— 那些值本来就只是"上一版的实现细节"
  • 不再保留 #3455db 这类"两套主色"（应用内 vs 认证页各一个蓝）
  • 不再用 4px 圆角 —— 密集控件在 4px 下显得硬，6px 更耐看
  • 不再靠阴影分隔列表行，改 1px 边线
保住的东西
  • 蓝色仍然是品牌色（#1f55db 是 #3455db 的收敛版，色相几乎不变）
  • 正文 14px、表格行高 40px —— 现有页面不会"变样"，只会变干净
  • 不引入 Web 字体、不引入 CSS 框架，仍是自研令牌 + 自研组件
  • space(n) 语义保持不变（n × 8px），现有调用零改动
迁移是增量的，不是重写。 第一步只把 theme.css 的语义层换掉、旧变量名保留为别名（--cf-color-primary: var(--ac-primary)）， 页面一行不改就能先看到新配色；第二步再逐页把旧变量名换成新语义名；第三步才动圆角与间距。 每一步都能单独回滚。
